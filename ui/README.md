# EcliptOS Marketplace UI

Next.js frontend for the EcliptOS Marketplace, providing a user-friendly interface for browsing, searching, and discovering MLRun functions, modules, and steps.

## Prerequisites

- Node.js 18+ and npm installed
- Marketplace must be built first (run `make build-marketplace` in the project root)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Build marketplace and copy data (from project root):
   ```bash
   # Build marketplace
   make build-marketplace
   
   # Copy marketplace data to ui/public/
   make copy-ui
   ```

## Development

### Option 1: Using Makefile (Recommended)

From the project root:
```bash
# Build marketplace, copy to UI, and start dev server (all in one)
make dev
```

### Option 2: Manual Steps

From the project root:
```bash
# 1. Build marketplace
make build-marketplace

# 2. Copy marketplace data to UI
make copy-ui

# 3. Start dev server (from ui/ directory)
cd ui && npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

**Important**: After rebuilding the marketplace, always run `make copy-ui` from the project root to update `ui/public/` with the latest data.

## Building

Build for production (static export):

```bash
npm run build
```

The output will be in the `out/` directory.

## Project Structure

```
ui/
├── src/
│   ├── app/              # Next.js App Router pages
│   ├── components/       # React components
│   └── lib/              # Utility functions (catalog loader, etc.)
├── public/               # Static assets and catalog data
└── package.json
```

## Catalog Data

The UI reads from `public/catalog.json` which is generated by the marketplace build process. 

**After rebuilding the marketplace**, run `make copy-ui` from the project root to update `ui/public/` with the latest data. This copies:
- `catalog.json`
- `functions/` directory
- `modules/` directory  
- `steps/` directory

The `ui/public/` directory is gitignored since it contains build artifacts that should be regenerated.
